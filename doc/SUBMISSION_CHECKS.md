# Research input and output verification

The private working project was previously checked in an independent checkout: 190 Python tests passed, with 104 existing numerical, pandas and performance warnings. That result describes the original checkout; it is not a claim that a new model was trained for this public export.

The public source export excludes course slides, media, rosters and rehearsal material. It retains the model code, data, saved final fits, forecasts and technical documentation. Two manifest paths are made relative, notebook execution outputs are cleared and the non-portable R selection cache is omitted. All 156 frozen dependency hashes remain identical. The omitted cache is regenerated by the selection runner when needed; the selected specification and final fitted model remain included.

## Data integrity and portability

`data/metadata/file_inventory.csv` records file sizes and SHA-256 hashes.
`data/metadata/submission_data_audit.json` records the independent data audit.
The approved main table still has 3,803 rows and 32 predictors. Its CSV/Parquet
pair, the 8,268-row long-history pair and the 3,803-row time-series target all
pass consistency checks. The negative WTI quote is retained.

The publication schedule has 3,726 archive-matched rows and 77 explicitly assumed
weekly releases. All three news-source hashes pass, with complete features at
all 17 October rolling origins under the approved release calendar. All 588
Kronos corpus files (3,574,348 bars) and both checkpoint stages are present.

Rebuild manifests, source support and held-out inputs were copied unchanged into
`data/rebuild/`; corpus and checkpoints now have explicit portable directories.
Original manifest paths are translated in memory. A fresh extraction successfully
rebuilt the dataset offline and reproduced the main table and publication
schedule. Independent validation verified:

- 3,232 input hashes and 31 output hashes;
- 11 CSV/Parquet pairs and 512 independently sampled as-of alignments;
- 10 temporal checks and an identical deterministic rerun;
- all 11 original source ZIP archives.

Integrity checks do not establish complete real-time vintages. The project's
documented release assumptions and retrospective evaluation limits remain.
